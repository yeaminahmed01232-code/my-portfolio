# YeaMin Portfolio Website

A responsive dark-premium portfolio inspired by the reference design you provided.

## Included
- Premium black/minimal layout
- Responsive desktop + mobile design
- Hero section with profile placeholder
- About section
- Portfolio/strategy cards
- Results section with editable placeholders
- Contact section
- Smooth scrolling and active navigation
- No framework required

## How to edit
1. Open `index.html` in a browser to preview it.
2. Replace the CSS portrait placeholder with your real photo later.
3. Change the email in the `mailto:` link.
4. Add your verified trading statistics in the Results section.
5. Add WhatsApp/Telegram links when you provide them.

Everything is plain HTML/CSS/JS, so it can be hosted on free static hosting later.
